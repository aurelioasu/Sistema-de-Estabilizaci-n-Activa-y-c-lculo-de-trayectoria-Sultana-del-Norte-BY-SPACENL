# Sultana del Norte v1.0.0

Primera publicación integral y curada del sistema de estabilización y corrección activa de vuelo de **Space NL**.

## Incluye

- diseño mecánico, modelo STL, renders y 72 resultados CFD organizados;
- esquemáticos, PCB, BOM interactiva y modelos electrónicos 3D;
- firmware de diagnóstico, vuelo y estación terrestre para ESP32-S3;
- código fuente completo de la aplicación Sultana del Norte en Python, C++ y Go;
- ejecutable único y paquete portable para Windows 10/11 x64;
- reporte técnico final, informe CAD y documentación de arquitectura;
- video principal, 162 fotografías/videos de evidencia y 12 recursos CAD dinámicos únicos.

## Antes de usar

Los ejecutables no cuentan con firma digital comercial, por lo que Windows SmartScreen puede mostrar una advertencia de editor desconocido. Compara la suma SHA-256 de tu descarga con `SHA256SUMS.txt`.

La aplicación funciona sin Docker para simulación, mapas, telemetría y análisis. Docker Desktop solo es necesario para ejecutar casos externos de OpenFOAM.

> [!CAUTION]
> Es software experimental. Revisa el pinout contra el hardware real, conserva los seguros de actuación desactivados durante pruebas de banco y nunca conectes una carga de despliegue directamente a un GPIO.
